# Nexus
NEXUS is an all-in-one personal dashboard and productivity suite built with vanilla web technologies. It provides dynamic task management, goal setting, daily schedule planning, and active focus time tracking without relying on external frameworks, cloud backends, or third-party data tracking.

Live Demo: nexus-routines.netlify.app


Key Features
> Focus & Activity Tracker: Active stopwatch recorder allowing users to choose activity categories (Studying, Running an Errand, Coding, or Custom) and log exact durations straight into local activity records upon completion.

> Daily Planner: Time-mapped schedule builder supporting specific event times, deadline tags, and dynamic rendering.

> Tasks & Goals: Priority-based task tracking integrated with long-term goal setting and progress tracking.

> Live Analytics: Automatically aggregates completed tasks and logged focus sessions into summary metrics, calculating completion rates, total focus hours, and active streaks.

> Theme Customization: Global dark and light mode toggle with accent color selection powered by CSS custom properties.

> Privacy & Local-First State: Data persists entirely within the browser via the localStorage API, ensuring instant loading, offline availability, and zero data leakage.

Tech Stack
Frontend: HTML5, Modern CSS3 (Flexbox, CSS Grid, Custom Variables)

Scripting: JavaScript (ES6+)

State Management: Web Storage API (localStorage)

Deployment: Netlify

Getting Started
Prerequisites
You only need a modern web browser (Google Chrome, Mozilla Firefox, Safari, or Microsoft Edge) to run NEXUS locally.
